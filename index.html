Quick setup

  1. Extract the ZIP.
  2. Double-click install.bat.
  3. Wait while Python, Ollama and the coding model install. Model download is around 1 GB.
  4. Use Ctrl + Shift + Space to show/hide the assistant.

Windows 10/11 • Internet required for first installation. After setup, prompts are processed locally.
